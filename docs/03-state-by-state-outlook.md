How to read this:
- **Favored** = the party the forecast leans toward. "Toss Up" = no clear favorite.
- **Probability** = Decision Desk HQ win probability for the favored side (DDHQ only names the side for Lean/Likely/Safe ratings).
- **Cook** = Cook Political Report rating where available.
- Machine-readable versions: [`data/senate_2026.csv`](../data/senate_2026.csv), [`data/governors_2026.csv`](../data/governors_2026.csv).
